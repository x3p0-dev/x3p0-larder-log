Larder Log

Warm oat gradient, brown lines, brick-crimson accent. Filters and settings share one left drawer — docked on desktop, a slide-over on mobile.

Add item

A sheet rather than an inline panel — 480px from the right on desktop, a bottom sheet on mobile. A selected chip inverts to ink; the term’s colour stays in the dot.

Edit item

The add sheet prefilled, with Remove in the footer — and the inline composer that creates a location, store or type without leaving it.

Store filter → shopping list

The shopping list stays contextual: filter by a store, the banner appears, the button opens that store’s low and out items.

Drawer states

Household switcher open, and a term set being edited in place from the Filter pane.

Collapsed rail

The drawer reduced to a 68px rail — quick-filter and menu flyouts beside it, panes expand it. Every control in five states.

Sort menu

Six options in three groups, the active one named on the trigger so the menu is only opened to change it.

Settings pane

Account, Household, Members, Appearance, Default threshold, Invites — at full height. No terms block, no shopping list.

Light mode tokens

Palette, sixteen term colors, type ramp and controls — the reference the dark mode gets built against.

Dark mode

Generated from the light boards by a hex-for-hex token map — same layout, same behaviour, swapped surface ramp.
