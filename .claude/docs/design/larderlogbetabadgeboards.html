The app's only two badges, at either end of the same 44px row — about 140px apart, with the wordmark between them. They stay apart on shape and colour — a ringed crimson circle riding the menu button versus a bordered neutral pill sitting in the row — and only the crimson one comes and goes. Worth looking at on a real screen before this is accepted. With the slide-over open, both sit inside the 328 and the badge is never drawn twice.

What lost

Four that lost
Each of them broke a rule the app already keeps
Kept Larder Log Beta Neutral, bordered, unpressable. It borrows no vocabulary that already means something else.
Larder Log Beta
Crimson — the filter-badge fill
Crimson already means gone on the status ramp and something is filtering on the rail. And Log is crimson — this doubles the only accent inside a 200px span.
2.49:1 on the raised fill — the cream text would have to carry it alone.
Larder Log Beta
Amber — the low tokens
Amber is "hold on" is nearly the right sentence. It loses on scope: the ramp is about stock, so this says the pantry is running low.
The low tint reads 1.03:1 on the ground — the same finding the shopping-list trigger already recorded.
Larder Log Beta
Inverted — ink fill
The selected-chip treatment, and it reads beautifully at this size. It breaks rule 3 of Theming outright: near-black ink is the only thing you press.
An unpressable ink pill would teach the app's own rule wrong on the first screen.
Larder Log beta
Playfair italic — rhyming with Log
It makes the badge part of the name rather than a marker on it — Larder Log Beta reads as the product. And like bare superscript text, it has no container to give it an edge.
The badge should look attached by the team, not typed by the designer.
