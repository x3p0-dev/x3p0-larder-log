What differs from the add sheet

The item names itself. The header carries the item rather than “Add an item” — the only place its name is set in Playfair at that size, so there is never a doubt about which row you opened.

Remove lives in the footer, far left. Always reachable without scrolling, and the width of the footer away from Save. Crimson text, never a crimson fill.

Removal is undoable, not confirmed. The sheet closes, the item goes, and a toast holds it for a few seconds. A modal asking “are you sure” on every edit is the worse trade in a shared list.

A selected chip inverts, it does not take the term's colour. Same signal as the filter pane and the quick-filter flyouts; the colour identifies the term, inversion says it is on.
